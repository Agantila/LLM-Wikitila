Das von `wikitila_graph.py` genutzte Paket ist `graphifyy` (https://github.com/safishamsi/graphify), Version 0.4.16, mit `networkx` 3.6.1. Der Importname ist `graphify`.
**Warum:** Die alte Doku nannte `pip install graphify`. Dieser Name gehört nicht zum genutzten Paket (Supply-Chain-Risiko).
**Anwenden:** Bei Versionswechsel Doku (installation DE/EN, README DE/EN) und diesen Eintrag gemeinsam ändern.
